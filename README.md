# Junior Data Engineer — 12-Week Roadmap

A full-time, hands-on learning journey focused on becoming job-ready for a Junior Data Engineer role.

This repository documents my progress through 12 weeks of structured learning, practical exercises, and production-style projects. The roadmap covers the core tools, concepts, and workflows used by modern data engineering teams, with a strong emphasis on writing clean code, building reliable data pipelines, and documenting technical decisions.

---

## Objectives

By the end of this roadmap, I aim to be able to:

- Write clean, modular, and testable Python code
- Use SQL confidently for querying, transforming, and analysing data
- Build reliable ETL and ELT pipelines
- Design and work with relational databases
- Model data for analytics and reporting
- Orchestrate workflows with Apache Airflow
- Transform data using dbt
- Process larger datasets with Apache Spark
- Work with common data formats such as CSV, JSON, and Parquet
- Containerise development environments with Docker
- Understand Microsoft Azure data engineering fundamentals
- Build and document an end-to-end data engineering project
- Prepare for Junior Data Engineer technical interviews

---

## Learning Approach

The roadmap follows a practical, project-based approach:

- **Duration:** 12 weeks
- **Schedule:** Full-time
- **Workload:** Approximately 35–40 hours per week
- **Focus:** 20% theory and 80% hands-on practice
- **Workflow:** Learn, practise, build, test, document, and review

Each week includes:

- Technical notes
- Coding exercises
- Practical assignments
- Mini-projects
- Documentation
- Git commits
- Review questions
- Interview preparation

---

## Weekly Roadmap

- [ ] **Week 1 — Python Foundations**
  - Python syntax, control flow, loops, collections, functions, file handling, and error handling

- [ ] **Week 2 — SQL**
  - Filtering, joins, aggregations, subqueries, CTEs, window functions, and query optimisation

- [ ] **Week 3 — ETL Pipelines**
  - Data extraction, transformation, validation, loading, logging, and error handling

- [ ] **Week 4 — PostgreSQL**
  - Relational database design, constraints, indexes, transactions, and Python integration

- [ ] **Week 5 — Apache Airflow**
  - DAGs, tasks, scheduling, dependencies, retries, monitoring, and pipeline orchestration

- [ ] **Week 6 — dbt**
  - Data transformation, models, tests, documentation, sources, and modular SQL workflows

- [ ] **Week 7 — Apache Spark**
  - Spark DataFrames, transformations, actions, partitioning, and distributed processing

- [ ] **Week 8 — Microsoft Azure**
  - Azure storage, data services, identity, security, and cloud-based data pipelines

- [ ] **Week 9 — Data Warehousing**
  - Dimensional modelling, fact tables, dimension tables, star schemas, and slowly changing dimensions

- [ ] **Week 10 — Streaming**
  - Streaming concepts, producers, consumers, event processing, and introductory Kafka workflows

- [ ] **Week 11 — Capstone Project**
  - Design and build an end-to-end data engineering solution using the tools learned throughout the roadmap

- [ ] **Week 12 — Interview Preparation**
  - SQL exercises, Python questions, system design basics, project presentation, and mock interviews
