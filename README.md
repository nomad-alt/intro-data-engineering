# Junior Data Engineer — 12-Week Study Project

A full-time, hands-on learning journey focused on developing practical
Junior Data Engineer skills through exercises, mini-projects, and an
end-to-end capstone project.

## Goal

Become job-ready for Junior Data Engineer positions by building practical
experience with Python, SQL, databases, pipelines, orchestration, data
transformation, distributed processing, cloud services, and data modelling.

## Weekly Roadmap

- [ ] Week 1 — Python for Data Engineering
