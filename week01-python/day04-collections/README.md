# Day 4 — Python Collections

## Objective

Learn how to store, access, transform, and validate groups of values using
Python collections.

## Topics Covered

- Lists
- List indexing and slicing
- List methods
- Tuples
- Sets
- Set operations
- Dictionaries
- Safe dictionary access
- Nested collections
- List comprehensions
- Dictionary comprehensions

## Files

- `src/collection_examples.py` — collection syntax and examples
- `src/exercises.py` — collection exercises
- `src/customer_validator.py` — customer validation mini-project
- `tests/test_customer_validator.py` — unit tests
- `notes.md` — learning notes

## Running the Programs

From the repository root:

```bash
python week01-python/day04-collections/src/collection_examples.py
python week01-python/day04-collections/src/exercises.py
python week01-python/day04-collections/src/customer_validator.py
