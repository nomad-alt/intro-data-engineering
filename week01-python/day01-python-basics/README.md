# Day 1 — Python Basics

## Objective

Learn the core Python syntax needed for future data-processing and ETL work.

## Topics Covered

- Variables
- Basic data types
- Type inspection
- Type conversion
- Arithmetic operators
- Comparison operators
- Logical operators
- User input
- String formatting

## Files

- `variables.py` — variable and data type examples
- `exercises.py` — practice exercises
- `bmi_calculator.py` — command-line BMI calculator
- `notes.md` — learning notes

## Running the Examples

From the repository root:

```bash
python week01-python/day01-python-basics/src/variables.py
python week01-python/day01-python-basics/src/exercises.py
python week01-python/day01-python-basics/src/bmi_calculator.py
